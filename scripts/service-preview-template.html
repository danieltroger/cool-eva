The service sheet, as it currently stands

Built from public/ on whatever branch is checked out. Real stylesheet, real markup, real behaviour — every panel below is the dashboard's own code running, not a picture of it.

Three of the buttons in this sheet looked identical until you read them, and one of them cannot be undone. Every control now carries a 3 px gutter down its left edge saying which of three things it is, and the three with no undo sit behind a fold that is shut every time the sheet opens.

Nothing here touches the bike. There is no Pi and no CAN bus at the other end: the readings are a stand-in with this bike's own numbers in them — 58 % charge, MAX_DC_CHG_CURRENT reading 75, parameter table 16407, the water-pump code that has been stored since before anyone looked. Buttons arm and fire against that stand-in, so the two-tap confirmations are real to press.
Rendered from public/ by scripts/build-service-preview.ts. Self-contained: no network at runtime.
