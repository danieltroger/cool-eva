# Reduction scripts for the key-off and clock-trust measurements

Every figure in `docs/power-cuts.md` §7 and `docs/ride-log-clock.md` is generated by these, not retyped. Issues #57 and #188.

```sh
# 1. reduce the candump archive to its events (~12 min, one sequential pass, 16 GB)
cd ~/Documents/cool-eva-archive
ls capture-*.log buttons-2026-08-19.log charge-2026-08-02-real.log charge.log \
   dtc-2026-08-02-*.log energica_probe.log energica_ride.log ride-1.log \
   ride-2026-08-02.log > /tmp/files.txt
: > events.txt
while read -r f; do
  echo "F $f" >> events.txt
  LC_ALL=C awk -f <repo>/evidence/keyoff/reduce-captures.awk "$f" >> events.txt
done < /tmp/files.txt
python3 <repo>/evidence/keyoff/tail-shape.py $(cat /tmp/files.txt) > tails.jsonl

# 2. the figures
python3 <repo>/evidence/keyoff/capture-figures.py events.txt tails.jsonl
python3 <repo>/evidence/keyoff/clock-figures.py <a read-only copy of rides.db>
```

`figures.txt` beside this file is the committed output of step 2, so a reader can check a number in the docs without the 16 GB.

## Two traps that cost real time, both caught in review

⚠️ **candump's column width moves _within_ one file.** `capture-20260808-193722-988ac089.log` prints `can0  101   [8]` early and `can0       101   [8]` later, so a fixed-space `grep ' can0  101 '` returns 234 020 of its 576 168 `0x101` frames — **59 % dropped, no error**. Everything here selects on `$4`, never on spacing.

⚠️ **Guard `NF`.** `capture-20260807-213353-999f16f6.log` ends `(2026-08-07 21:38:22.623151)  can0  101   [8]` with the data bytes cut off mid-line by the power cut. Ungarded that reads as a state change at the file's last instant and moves a capture between populations — and a truncated last line is the _power-cut signature itself_ (`tail-shape.py`), so it is common, not exotic.

⚠️ **The wall clock in these files steps.** 40 of the 97 files carry a discontinuity, and an interval measured across one is not a duration — `docs/can-0x101.md` records a 317 s figure retracted to exactly this. Every interval here is refused if one lies inside it, **including an inverted one**: a backward step puts `end` before `start`, and a range test that does not check for that silently passes the worst interval in the corpus.

## Corpus, stated rather than left to a glob

255 files: 246 `capture-*.log` plus `buttons-2026-08-19.log`, `charge.log`, `charge-2026-08-02-real.log`, the two `dtc-2026-08-02-*.log`, `energica_probe.log`, `energica_ride.log`, `ride-1.log`, `ride-2026-08-02.log`. 97 carry frames.

- `ride-1.log` and `ride-2026-08-02.log` are byte-identical, so one file is counted twice.
- `can_log-2026-06-14.txt` is excluded: epoch-and-hex framing, not `candump -tA`.
- `ride-captures3/`'s 59 files are excluded as duplicates — all 59, across all seven of its boot ids, duplicate top-level files, so no boot is missed and no terminal capture is misidentified.
